# Direct Total Commander launch

The old `Arthur.mscr` menu is retired. Run `python3 tools/prepare_total_commander.py` from the repository root.

For the head unit's Navigation button, replace the SD card's whole `Navigation` directory with the generated `dist/total-commander-direct/Navigation` directory. Its `Navigation.exe` is Total Commander itself.

The generated `dist/total-commander-direct/LaunchTotalCommander/LaunchTotalCommander.exe` is an optional identical direct entry point. This source directory is documentation, not a ready-to-run SD installation. See the root README for SD verification and troubleshooting.
